# Simple Task List & Theme Switcher

Uma aplicação web simples de lista de tarefas com alternância dinâmica entre modo claro (Light Mode) e modo escuro (Dark Mode), desenvolvida com HTML5, CSS3 moderno e JavaScript puro.

---

## Funcionalidades

- Alternância de Tema: Troca entre modo claro e escuro em tempo real.
- CSS Custom Properties (Variáveis CSS): Controle unificado de paleta de cores.
- Layout Responsivo: Estrutura flexível e centralizada em qualquer tamanho de tela.
- Acessibilidade: Suporte a foco via teclado e fallbacks semânticos.

---

## Tecnologias Utilizadas

- HTML5
- CSS3 (Flexbox e variáveis nativas)
- JavaScript (ES6+) (Manipulação de classes e DOM)
